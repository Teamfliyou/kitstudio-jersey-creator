# KitStudio – Créateur de maillots

Web app autonome (un seul fichier HTML, sans dépendance) pour créer des maillots de sport.

- Motifs, couleurs, encolure, manches, épaulettes
- Nom, numéro, polices, écusson (4 formes ou logo importé)
- **v2 : sponsors** – 10 logos fictifs, texte ou logo importé, sur 6 emplacements (poitrine, dos, manches, équipementier, short)
- Vues face / dos / tenue complète, galerie locale, lien partageable
- Export PNG et SVG

Ouvrir `index.html` dans un navigateur.
